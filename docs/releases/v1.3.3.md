# v1.3.3 - 开局问卷：自写答案不再被强行归类

## 本次修复

- **自写答案不再被强行归类**：以前在问卷里点「都不像我 → 自己写」之后，那句话会被硬塞进你上一次点过的那个选项对应的结论；现在自定义作答**只算「已作答」，不投票**。
  - 归结论靠词元映射（例句里的 `the` / `a` 这类虚词不再拉偏），像 `wa` 和 `watch` 这种近似词也不会互相误伤。
  - 词元映射归不出来时才问 AI，**AI 的归类结果必须由玩家确认**（可改可拒），不会再默默替你定。
- **切换自定义会清掉旧选项**：改填自定义答案时，之前选过的同题选项一并清除，避免「两个答案同时生效」。
- **下一步不再卡住**：「还有 N 道题没选」的计数把自定义作答也算进去——写了字的题不再被当成没答。
- **没有票就没有结论**：一票都没有时返回空，而不是拿「先声明」的结论凑数。
- **修掉一个显示问题**：问卷结论里出现 `[object Object]`（把对象直接拼进文案）。

## 验证

- 自动化：`test_quiz_custom.js` 22/22；RN jest 9 套 17/17；桌面 95 套单测（含引擎同步）全绿。
