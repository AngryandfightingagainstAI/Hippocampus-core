# 神秘小引擎（Hippocampus）

**手机上就能玩的 AI 文字冒险。AI 当主持人，剧情当场编，存档只留在你自己手机里。**

不用注册、不用买服务器、不用等别人开服。你给它一个世界（我们叫「卡带」），它让 AI 当主持人陪你往下玩：讲故事、演 NPC、记数值、管时间。

> 版本：1.3.1 ｜ Android 7.0+ ｜ 另有 Windows 桌面版 ｜ MIT 许可
> 项目现状：40 套 RN smoke 共 2625 条断言全绿；桌面版另有 14 项预检 + 67 套回归。

---

## 这是什么？三句话说清

1. **你选一个世界**：App 首屏自带一张示例卡带；想玩自己的世界，就导入一张（见下面「我不会写设定怎么办」）。
2. **AI 当主持人**：它一轮一轮往下写故事、演 NPC、算数值，还会在剧情之外给你发「手机讯息」。
3. **你来决定**：每轮都有几个选项按钮，也可以自己打字说「我要推开门」。

就这么简单——它更像「有个 AI 陪你跑团」，而不是「跟 AI 聊天」。

## 三分钟开始玩

### 第 1 步：装到手机上

👉 **[下载最新 APK](https://github.com/AngryandfightingagainstAI/Hippocampus-core/releases/latest)**

在 Release 页面点最新那条，下载 `.apk` 文件，点开安装。
第一次装会提示「未知来源应用」，允许一次即可（国产 ROM 常有「安全守护」拦截页，点「已了解风险」→「继续安装」）。
每个 Release 都写了版本号与 SHA256，介意的话可以自己核对。

### 第 2 步：打开，直接开玩

首屏自带一张「示例卡带」，点 **02 新建存档** 就能玩，什么都不用准备。

### 第 3 步：接上 AI（想现在才接也行）

**设置 → 🤖 AI**：

- **有 API Key**：填 Base URL、模型名、Key 就行。OpenAI、DeepSeek、通义、Kimi、Gemini、各种中转站、本机 Ollama 都支持（只要是 OpenAI 兼容接口）。
- **没有 Key、也不想花钱**：把「对话通道」切成 **外部 AI（手动复制 → 粘贴）**。这种模式下 App 完全不联网：它把这一轮的提示词给你复制走，你交给任意一个网页版 AI，再把回复粘回来提交。多两步操作，但一分钱不花、也不用把 Key 填进来。

## 我不会写设定，也想玩自己的世界

三条路，都不用你会写代码：

**① 让 AI 替你写。**
打开 **卡带库 → 生成卡带指令**，里面是 6 段「怎么让 AI 写一张合格卡带」的提示词。第 1 段（骨架）必给，后面按需要追加，复制给你的 AI（ChatGPT / DeepSeek / Claude 都行），它就会吐出一份卡带 JSON。

**② 把现成的资料丢进去。**
**卡带库 → 导入文游资料**：txt / md / csv / docx / pdf / epub 这类设定文档粘进去（手机上也能直接选文件），引擎会先解析成「卡带草稿」，把缺的部分列出来，再让 AI 补。

**③ 粘回来导入。**
拿到 JSON 后粘进「粘贴卡带 JSON」框点 **诊断并导入**。导入前它会先体检：缺哪个面板、哪个字段没填、哪条引用断了，都会明确告诉你——**有问题不硬塞，先修再进**。

## 玩起来有什么

| 你会用到的 | 说明 |
|---|---|
| 叙事页 | 选项按钮 + 自定义行动；能「重新生成」最新一轮，也能「回到这里」退回到某轮 |
| 思考链 | 模型的推理过程、联网搜索、token 用量，三块都能单独关掉 |
| 骰子 | `1d100`、对抗检定、`/ra50` 简写，历史可查 |
| 手机讯息 | AI 会在剧情之外给你发短信 / 广播，有未读红点；要不要进正文由你决定 |
| 角色卡 | 属性、名声、关系、物品、世界书命中项，一屏看完 |
| 世界书 | 世界观、NPC、种族、职业、技能、物品、商店、势力、货币、地图、时间线、产出物，12 个子编辑器 |
| 主题 | 纸白 / 流光 / 古卷，还能导入别人做的主题包 |
| 存档 | 随时存、随时读；卸载或清数据会一起删掉，重要存档记得用「数据」页导出 |

## 常见问题

**要不要花钱？**
软件本身免费开源（MIT）。AI 的钱是付给模型商的，按你自己的用量算。
一分钱都不想花也能玩：用「外部 AI」通道，把回复粘回来就行，App 这边不产生任何请求。

**存档在哪？会被上传吗？**
在手机本地，不上传，也没有账号。卸载或清数据会一起删掉；要留就导出备份。

**支持 iPhone 吗？**
暂不支持。目前只做了 Android；`ios/` 还是脚手架状态。

**AI 会不会玩着玩着忘掉前面？**
每回合引擎会重新拼一份「当前状态」给 AI（数值、在场 NPC、时间、未读讯息等），历史太长时会把旧对话压成日志。所以它比普通 AI 聊天抗忘，但长局依然会有偏差，这不是彻底解决方案。

**AI 会不会乱改我的数值？**
所有世界改动只能通过受限的工具调用完成。而且某一轮工具全部失败却动了数值时，引擎会自动回滚并让 AI 重来。

**能联机 / 多人吗？**
不能。单人、纯本地。

**我没电脑，能自己加卡带吗？**
能。手机上就能导入 JSON，也能用「导入文游资料」吃文档。只有打包 APK、改代码才需要电脑。

## 已知限制（先说清楚，免得到了那一步才发现）

- **只有 Android**：iOS 一侧没做（原生模块只写了 Android，`ios/` 是模板脚手架）。
- **手机版导入大文件要注意**：文本类可以粘贴或选文件；docx / odt / epub / PDF / ZIP 这类，在手机上解析会慢，建议用桌面版导入后再导出卡带。
- **手机讯息是概率性的**：有冷却与概率，连着几轮没收到短信是正常的，只有第一条保证送达。
- **农历节日不做**：每年日期不同，引擎暂不支持。
- **设置页切换不拦**：只有涉及世界书的切换会提示保存，其它页是即时生效的。
- **主页装扮跟卡带走，不跟全局主题走**：首页的书票样式（纸白 / 流光 / 古卷）由这张卡带的 `display` 决定，也可以在主页面板里临时切换；你在「设置 → 主题」里选的主题影响的是其它页面。这是有意为之——换卡带时，封面跟着换。
